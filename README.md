# hunarbatra.com

Personal website. Single page (`index.html`) with no build step.

- `scholar.json`: citation count shown on the page, refreshed daily by `.github/workflows/scholar.yml` (add a `SERPAPI_KEY` repo secret for reliable updates).
- `llms.txt`, `robots.txt`: notes for AI agents and crawlers.
- `CNAME`: custom domain for GitHub Pages.
